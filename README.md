# Port4lio

Portfolio website for Mwangolo Fredrick Karimah, built with React and Vite.

## About

This portfolio showcases skills in data science, business analysis, graphic design, and web development. It includes sections for home, about, projects, skills, and contact information.

## Tech stack

- React 19
- Vite 7
- Bootstrap 5
- React Router 7
- ESLint

## Local development

```bash
npm install
npm run dev
```

Open the local server address shown in the terminal to view the portfolio.

## Build

```bash
npm run build
```

## Repository

GitHub: https://github.com/Karim08F/Port4lio

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
